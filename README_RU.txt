ПРОЕКТ: УПРАВЛЕНИЕ БИБЛИОТЕКОЙ

Что сделано:
- ASP.NET Core MVC + SQLite.
- Добавление и просмотр книг.
- Поиск книги по названию, автору и году.
- Регистрация и список читателей.
- Выдача и возврат книги.
- Проверка доступности и регистрации читателя.
- Статистика библиотеки.
- Подсчёт возраста книги, сортировка по году, рекурсивный подсчёт.
- Статический метод названия библиотеки и расчёта штрафа.
- Главное меню сайта.

КАК ОТКРЫТЬ В VISUAL STUDIO 2022:
1. Распакуйте ZIP в папку, например C:\Projects\LibraryManagement.
2. Откройте Visual Studio 2022.
3. Нажмите File -> Open -> Project/Solution.
4. Выберите файл LibraryManagement.csproj.
5. Дождитесь восстановления NuGet-пакетов. Нужен .NET 8 SDK.
6. Нажмите зелёную кнопку запуска (https).
7. Откроется сайт. База library.db создаётся автоматически рядом с проектом.

ЕСЛИ ОТКРЫВАЕТЕ ЧЕРЕЗ ТЕРМИНАЛ:
Откройте терминал в папке проекта и выполните:
dotnet restore
dotnet run

Затем откройте адрес, который покажет терминал (обычно https://localhost:xxxx).

ВАЖНО:
- Штраф в этом учебном примере: 100 условных единиц за день после 14 дней.
- SQLite-файл library.db создаётся при первом запуске.
- Если Visual Studio предлагает доверять HTTPS-сертификату, подтвердите для локальной разработки.


ОБНОВЛЕНИЕ: ЛИЧНЫЕ КАБИНЕТЫ И РАСШИРЕННЫЙ КАТАЛОГ
- В карточке книги: описание, обложка (JPG/PNG/WEBP до 5 МБ), ссылка на YouTube.
- Откройте книгу кнопкой «Подробнее», чтобы увидеть описание и встроенный YouTube-плеер.
- У читателя есть личный кабинет: ФИО, дата рождения, учёба/работа, организация, ИИН, почта, телефон и пол.
- Новые поля добавляются в существующую SQLite-базу автоматически при запуске; старые записи сохраняются.
- Загруженные обложки хранятся в wwwroot/uploads/covers.

ВАЖНО О ПЕРСОНАЛЬНЫХ ДАННЫХ:
Это учебный проект. Не вводите настоящие ИИН и реальные персональные данные несовершеннолетних.
Для реального использования нужна отдельная защита персональных данных, ограничение доступа и защищённое хранение.
